> **「Baekjoon（BOJ）ゴールドレベルの問題を、AI の助けなしに自力で解ける力を養う」**
>
> 本勉強会は、Web 開発力の土台となる問題解決能力を鍛えるために企画されました。

---

## 👥 メンバー
- **Member A（自分）:** フロント／バックエンドを学習中（C++ のポインタ・クラスに習熟）
- **Member B（先輩）:** 大学の先輩（C++ のポインタに習熟、データ構造を履修中）

## 🎯 目標
1. **No AI Policy:** 問題を解くときは生成 AI の助けを借りず、自力で実装する。
2. **C++ STL のマスター:** `vector`, `sort`, `stack`, `queue` など必須ライブラリを使いこなす。
3. **学校の成績とのシナジー:** C 言語のデータ構造の授業と並行し、理論と実装力を同時に身につける。

## 📁 リポジトリ構成（実際の実装コード）

週ごとのフォルダに Baekjoon (BOJ) の解答コード（`.cpp`）が整理されています。以下は各フォルダに実際に含まれるテーマと代表的な問題です。

> 注: 実際の実装順の都合で **貪欲法と DP の週の順序** はロードマップ計画と逆になっており、`week6` に DP、`week7` に貪欲法が入っています。

| フォルダ | テーマ | 代表ファイル（問題） |
| :--- | :--- | :--- |
| `week1/` | **ソート & 計算量** | `timeComplex`(15552 Fast I/O), `sortWithVector`(2750), `minMax`(10818), `ageSort`(10814), `coorSort`(11650) |
| `week2/` | **基礎データ構造 (Stack・Queue)** | `stack`, `queue`, `stackseq`（スタック数列）, `yosefus`（ヨセフス） |
| `week3/` | **全探索 & バックトラッキング** | `blackjack`(2798、順列/組合せ/三重ループの 3 通りを比較), `lotto`, `nm`(N と M), `nqueen`(N-Queen) |
| `week4/` | **グラフ探索 (BFS・DFS)** | `dfsbfs`(1260), `mindist`（迷路探索）, `tomato`（トマト）, `cabbage`（有機農白菜）, `worm_bfs`・`worm_dfs`（ウイルス） |
| `week5/` | **二分探索 & パラメトリックサーチ** | `binary_Search`(1920), `wood`（木を切る）, `lan`（LAN ケーブルを切る）, `router`（ルーター設置） |
| `week6/` | **動的計画法 (DP)** | `fibo`（フィボナッチ）, `make1`（1 にする）, `123sum`（1・2・3 の足し算）, `2ntile`（2×n タイリング）, `rgb`（RGB 通り）, `baggage`（ナップサック） |
| `week7/` | **貪欲法 & ヒープ** | `coin_zero`（コイン 0）, `meeting`（会議室割り当て）, `cards`（カードのソート・min-heap）, `maxheap`（最大ヒープ） |
| `week8/` | **最短経路 (Dijkstra・Floyd)** | `mindist`(1753), `mindist_bus`(1916), `mindist_spec`(1504 特定の最短経路), `floyd`（ワーシャル–フロイド） |

各コードは勉強会の **No AI Policy** に従って自力で実装しており、全探索の週のブラックジャックのように、同じ問題を順列／組合せ／ループなど複数の方法で実装して計算量の違いを比較した例も含まれています。
